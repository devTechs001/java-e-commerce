# Database Schema

## Entities

### User
- id, email, password (BCrypt), firstName, lastName, role, active, createdAt

### Product
- id, name, description, price, discountPrice, imageUrl, brand, sku, stockQuantity, active, featured, newArrival
- category_id, seller_email

### Category
- id, name, slug, description

### Cart
- id, userId, total, itemCount

### CartItem
- id, cartId, productId, productName, productImage, price, quantity

### Order
- id, userId, total, status, shippingAddress, city, postalCode, country, createdAt

### OrderItem
- id, orderId, productId, productName, productImage, price, quantity

### Address
- id, userId, street, city, postalCode, country, isDefault

### Payment
- id, orderId, amount, paymentMethod, status, transactionId

### Review
- id, productId, userId, rating, comment, createdAt

## Indexes

- Product: `idx_product_name` on name, `idx_product_category` on category_id
- User: `idx_user_email` on email
- Order: `idx_order_user` on user_id

## Migration Strategy

Schema is auto-generated by Hibernate (`ddl-auto: update`). For production, use Flyway/Liquibase.
