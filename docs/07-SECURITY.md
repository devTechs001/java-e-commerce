# Security

## Authentication

- JWT tokens signed with HS256 algorithm
- Token expiry: configurable via `JWT_EXPIRATION` (default 24h)
- Token stored client-side in `localStorage`
- Request interceptor adds `Authorization: Bearer <token>` header
- On 401 response, token is cleared and user redirected to login

## Password Handling

- BCrypt password hashing
- Salt: auto-generated by Spring Security

## CORS

Configured for all origins in development. Restrict in production.

## HTTPS

Use reverse proxy (nginx) for TLS termination in production.

## Best Practices

1. Change default JWT secret in production
2. Use HTTPS in production
3. Store secrets in environment variables or secret manager
4. Validate all user input
5. Use parameterized queries (JPA handles this)
